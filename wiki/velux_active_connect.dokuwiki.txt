====== VELUX Active Connect ======\n\n===== Beschreibung =====\n\n**VELUX Active Connect** verbindet VELUX ACTIVE / VELUX App Control mit LoxBerry und Loxone. Das Plugin liest Räume, Geräte und Sensorwerte über die VELUX Cloud aus, überträgt ausgewählte Werte per UDP an Loxone und ermöglicht die Steuerung von Dachfenstern, Rollläden und weiteren unterstützten Aktoren.\n\nFür Dachfenster, die signierte Positionsbefehle benötigen, kann das VELUX Gateway einmalig direkt über das lokale Netzwerk gekoppelt werden.\n\n===== Funktionen =====\n\n  * VELUX Cloud Login mit automatischer Token-Erneuerung\n  * Homes, Räume und Geräte automatisch erkennen\n  * Temperatur, Luftfeuchtigkeit, CO2, Helligkeit und Luftqualität\n  * Regensignal, sofern vom Gateway gemeldet\n  * Positions- und Erreichbarkeitswerte von Aktoren\n  * UDP-Ausgabe an einen in LoxBerry konfigurierten Miniserver\n  * Jede UDP Message einzeln aktivierbar und frei benennbar\n  * Wahlweise alle Werte oder nur geänderte Werte senden\n  * Heartbeat an Loxone\n  * Steuerung über Weboberfläche und Loxone UDP\n  * AUF, STOP, ZU und Position 0–100 %\n  * Lokale Gateway-Kopplung für signierte Dachfensterbefehle\n  * Konfiguration und Kopplung bleiben bei Plugin-Updates erhalten\n  * AutoUpdate über GitHub\n\n===== Voraussetzungen =====\n\n  * LoxBerry\n  * VELUX ACTIVE oder VELUX App Control\n  * VELUX Benutzerkonto\n  * Internetzugang des LoxBerry für die VELUX Cloud\n  * Für Gateway-Kopplung: LoxBerry und VELUX Gateway im gleichen Netzwerk\n  * TCP Port 25050 vom LoxBerry zum Gateway erreichbar\n\n===== Installation =====\n\nDie aktuelle ZIP-Datei aus dem GitHub Release herunterladen und über die LoxBerry Plugin-Verwaltung installieren.\n\nNach der Installation das Plugin öffnen und unter **Einstellungen** die VELUX Zugangsdaten hinterlegen.\n\n===== Einstellungen =====\n\n==== VELUX Zugang ====\n\n  * E-Mail des VELUX ACTIVE Kontos\n  * Passwort\n  * Abrufintervall\n\n==== UDP Statuswerte an Loxone ====\n\n  * UDP aktivieren\n  * Miniserver aus der LoxBerry Grundkonfiguration auswählen\n  * UDP Sendeport zum Miniserver\n  * Status-Präfix, standardmäßig ''velux''\n  * Heartbeat aktivieren und Namen festlegen\n  * Neue Werte automatisch für UDP aktivieren\n  * Sendeverhalten: alle Werte oder nur geänderte Werte\n\n==== Loxone zu VELUX Steuerung ====\n\n  * UDP-Steuerung aktivieren\n  * UDP Empfangsport am LoxBerry\n  * Befehls-Präfix, standardmäßig ''velux.cmd''\n\n==== VELUX Gateway Kopplung ====\n\nDie Kopplung wird für signierte Positionsbefehle von Dachfenstern benötigt.\n\n  - Gateway-IP eintragen\n  - Erkanntes Gateway auswählen\n  - **Gateway koppeln** starten\n  - Den Anweisungen folgen und die Taste am VELUX Gateway drücken\n  - Nach erfolgreicher Kopplung wird der Status als **Gekoppelt** angezeigt\n\nDie Signierschlüssel werden lokal gespeichert und bei Updates erhalten.\n\n===== Status =====\n\nDie Startseite zeigt kompakt:\n\n  * **Status: Verbunden / Fehler**\n  * **Gateway Kopplung: Gekoppelt / Nicht gekoppelt**\n  * Letzter Abruf\n  * Anzahl Homes, Räume, Geräte und Werte\n  * Anzahl gesendeter UDP Messages\n\nDarunter werden erkannte Geräte und aktuelle Werte angezeigt.\n\n===== UDP Messages =====\n\nAuf dieser Seite können alle erkannten Werte einzeln für UDP aktiviert oder deaktiviert und die Namen der UDP Messages geändert werden.\n\nBeispiel:\n\n<code>\nvelux.room.bad.temperature=26.7\nvelux.module.dachfenster_bad.position=50\nvelux.heartbeat=1\n</code>\n\n===== Steuerung =====\n\nErkannte Aktoren können direkt im Plugin getestet werden:\n\n  * AUF\n  * STOP\n  * ZU\n  * Position 0–100 %\n\nZusätzlich zeigt die Steuerungsseite den letzten empfangenen UDP-Befehl und das Resultat.\n\n==== Loxone Beispiel ====\n\nBeim jeweiligen Aktor kann **Loxone Beispiel anzeigen** geöffnet werden. IP, Port, Präfix und Geräte-Key werden automatisch aus der aktuellen Konfiguration erzeugt.\n\nVirtueller UDP-Ausgang:\n\n<code>\n/dev/udp/LOXBERRY-IP/7001\n</code>\n\n**Verbindung nach Senden schließen:** aktivieren.\n\nAUF – Befehl bei EIN:\n\n<code>\nvelux.cmd.dachfenster_bad.open=1\n</code>\n\nSTOP – Befehl bei EIN:\n\n<code>\nvelux.cmd.dachfenster_bad.stop=1\n</code>\n\nZU – Befehl bei EIN:\n\n<code>\nvelux.cmd.dachfenster_bad.close=1\n</code>\n\nBefehl bei AUS jeweils leer lassen.\n\nPosition – analoger Ausgangsbefehl:\n\n<code>\nvelux.cmd.dachfenster_bad.position=<v>\n</code>\n\n===== Log =====\n\nDas Plugin protokolliert unter anderem:\n\n  * Start des Workers\n  * Login / Token Refresh\n  * Homes und Gerätestatus\n  * Gelesene Werte\n  * UDP-Fehler und Anzahl gesendeter Nachrichten\n  * Empfangene Loxone Steuerbefehle\n  * VELUX Steuerantworten\n  * Gateway-Kopplung und Fehler\n\nPasswort und Token werden nicht im Klartext geloggt.\n\n===== Regensensor =====\n\nDas Plugin liest das von VELUX gemeldete Regensignal aus, sofern es vom Gateway bereitgestellt wird. Der Wert kann durch die Cloud verzögert sein und sollte daher nur als Information und nicht als sicherheitskritischer Regensensor verwendet werden.\n\n===== Update =====\n\nDie Plugin-Konfiguration, Tokens, UDP-Einstellungen und Gateway-Kopplung werden vor einem Update gesichert und danach wiederhergestellt.\n\nAutoUpdate nutzt die Dateien ''release.cfg'' und ''prerelease.cfg'' im GitHub Repository.\n\n===== Fehlersuche =====\n\n==== Keine VELUX Daten ====\n\n  * E-Mail und Passwort prüfen\n  * Log öffnen\n  * **Login komplett neu testen** verwenden\n\n==== UDP Status kommt nicht in Loxone an ====\n\n  * Miniserver-Auswahl prüfen\n  * Sendeport prüfen\n  * UDP Message aktivieren\n  * Log auf UDP-Warnungen prüfen\n\n==== Loxone Steuerbefehl kommt nicht an ====\n\n  * UDP-Steuerung aktivieren\n  * Empfangsport prüfen\n  * Virtuellen UDP-Ausgang auf ''/dev/udp/LOXBERRY-IP/PORT'' setzen\n  * **Verbindung nach Senden schließen** aktivieren\n  * UDP Empfangsdiagnose / Selbsttest verwenden\n\n==== Position eines Dachfensters funktioniert nicht ====\n\nWenn ZU und STOP funktionieren, aber Position mit VELUX Fehlercode 9 abgelehnt wird, muss das VELUX Gateway gekoppelt werden.\n\n===== GitHub =====\n\nRepository:\n\n  * https://github.com/fuul1984/loxberry-plugin-velux-active-connect\n\n===== Lizenz =====\n\nMIT License.\n
